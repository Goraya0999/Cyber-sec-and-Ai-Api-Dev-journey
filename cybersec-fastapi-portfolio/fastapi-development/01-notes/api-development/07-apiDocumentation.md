# FastAPI API Documentation

## Overview

FastAPI automatically generates API documentation based on your endpoints.

When a FastAPI application starts, it generates:

* Swagger UI (`/docs`)
* ReDoc (`/redoc`)
* OpenAPI Schema (`/openapi.json`)

These tools help developers understand, test, and integrate APIs.

---

# Swagger UI (`/docs`)

## What Is It?

Swagger UI is an interactive API documentation interface.

It allows developers to:

* View endpoints
* Test requests
* Send data
* View responses
* Understand API structure

## URL

```text
http://127.0.0.1:8000/docs
```

## Example

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello FastAPI"}
```

Start server:

```bash
uvicorn main:app --reload
```

Open:

```text
http://127.0.0.1:8000/docs
```

---

# ReDoc (`/redoc`)

## What Is It?

ReDoc is another API documentation interface generated by FastAPI.

Compared to Swagger:

* Cleaner design
* Better for reading documentation
* Less interactive
* More suitable for API consumers

## URL

```text
http://127.0.0.1:8000/redoc
```

## Example

No additional installation required.

FastAPI automatically generates it.

---

# OpenAPI Schema (`/openapi.json`)

## What Is It?

OpenAPI Schema is a machine-readable JSON file describing the entire API.

It contains:

* Endpoints
* Parameters
* Request bodies
* Response schemas
* Security definitions

## URL

```text
http://127.0.0.1:8000/openapi.json
```

## Example Output

```json
{
  "openapi": "3.1.0",
  "info": {
    "title": "FastAPI",
    "version": "0.1.0"
  }
}
```

## Why It Is Important

Many tools use OpenAPI schema to:

* Generate client SDKs
* Generate documentation
* Import APIs into Postman
* Create API testing workflows

# Scalar Documentation

## What Is Scalar?

Scalar is a modern API documentation interface built on top of OpenAPI.

Features:

* Modern UI
* Better navigation
* Dark mode
* Improved readability
* Interactive testing

---

# Install Scalar

Install package:

```bash
pip install scalar-fastapi
```

---

# Import Scalar

```python
from fastapi import FastAPI
from scalar_fastapi import get_scalar_api_reference
from fastapi.responses import HTMLResponse
```

---

# Create Scalar Endpoint

```python
from fastapi import FastAPI
from scalar_fastapi import get_scalar_api_reference

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello"}

@app.get("/scalar", include_in_schema=False)
async def scalar_html():
    return get_scalar_api_reference(
        openapi_url=app.openapi_url,
        title="My API"
    )
```

---

# Access Scalar

Open:

```text
http://127.0.0.1:8000/scalar
```

---

# Hide Endpoint From Documentation

Sometimes internal endpoints should not appear in:

* Swagger
* ReDoc
* OpenAPI Schema

Use:

```python
include_in_schema=False
```

---

# Example

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Visible"}

@app.get("/admin", include_in_schema=False)
def admin():
    return {"message": "Hidden"}
```

---

# Result

Visible in documentation:

```text
/
```

Hidden from documentation:

```text
/admin
```

The endpoint still works normally.

---

# Disable Swagger UI

```python
from fastapi import FastAPI

app = FastAPI(
    docs_url=None
)
```

Result:

```text
/docs
```

returns:

```text
404 Not Found
```

# Postman

## What Is Postman?

Postman is an API testing and development tool.

It allows developers to:

* Send HTTP requests
* Test endpoints
* View responses
* Manage collections
* Automate API testing

---

# Install Postman on Linux

## Snap Installation

```bash
sudo snap install postman
```

---

# Start Postman

```bash
postman
```

or

```text
Applications → Postman
```

---

# Testing FastAPI Endpoint in Postman

Example endpoint:

```python
@app.get("/users")
def users():
    return {"message": "Users Endpoint"}
```

Start FastAPI:

```bash
uvicorn main:app --reload
```

Request:

```http
GET http://127.0.0.1:8000/users
```

Response:

```json
{
  "message": "Users Endpoint"
}
```

---

# Import FastAPI Into Postman

Using OpenAPI schema:

```text
http://127.0.0.1:8000/openapi.json
```

Steps:

1. Open Postman.
2. Click Import.
3. Select Link.
4. Paste OpenAPI URL.
5. Click Import.

Postman automatically creates requests for all API endpoints.
