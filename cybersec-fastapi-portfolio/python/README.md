# Python Fundamentals

Core language work that underpins both the cybersecurity and FastAPI tracks:
language fundamentals, OOP, data structures, and algorithms, plus general
automation/utility scripts that aren't specific to either domain.

## Folder Map
| Folder | Contents |
|---|---|
| `core-python/` | Syntax, built-ins, standard library notes |
| `oop/` | Object-oriented programming concepts and patterns |
| `data-structures/` | Implementations and notes (lists, stacks, trees, graphs, hash maps) |
| `algorithms/` | Sorting, searching, recursion, complexity analysis |
| `automation-scripts/` | General-purpose automation, not security- or FastAPI-specific |
| `utility-scripts/` | Small reusable helpers (converters, parsers, CLI tools) |
