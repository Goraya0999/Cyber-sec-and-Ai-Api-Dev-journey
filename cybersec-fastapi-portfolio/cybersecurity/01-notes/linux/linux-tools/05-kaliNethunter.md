# Kali Linux NetHunter



# What is Kali NetHunter?

**Kali NetHunter** is an **open-source mobile penetration testing platform** designed for **Android devices**.

It brings the power of **Kali Linux** to smartphones and tablets.

# NetHunter vs Kali Linux

| Feature | Kali Linux | Kali NetHunter |
|---------|------------|----------------|
| Platform | Desktop/Laptop | Android Phone/Tablet |
| Mobility | Low | High |
| Touchscreen Support | No | Yes |
| External Wi-Fi Adapter | Yes | Yes |
| USB HID Support | Limited | Yes |
| Portable | Moderate | Excellent |
| Designed For | Desktop Penetration Testing | Mobile Penetration Testing |
