# Sniffing Tools

| Tool Name | Interface | Description |
|------------|-----------|-------------|
| **Dnschef** | Command Line | A DNS proxy tool that intercepts, modifies, and redirects DNS requests during penetration testing and security assessments. |
| **Dsniff** | Command Line | A collection of network auditing tools used to capture, monitor, and analyze plaintext network traffic such as passwords and other sensitive information. |
| **Netsniff-ng** | Command Line | A high-performance packet sniffer and network analyzer designed to capture network traffic efficiently with minimal system resource usage. |

---

# Spoofing and Man-in-the-Middle (MITM) Tools

| Tool Name | Interface | Description |
|------------|-----------|-------------|
| **DNS-rebind** | Command Line | A testing tool that exploits DNS rebinding vulnerabilities to simulate cross-origin attacks against vulnerable web applications and systems. |
| **SSLsplit** | Command Line | A Man-in-the-Middle (MITM) tool that intercepts, decrypts, and analyzes SSL/TLS encrypted traffic for security testing. |
| **tcpreplay** | Command Line | A network traffic replay tool used to send previously captured packets back onto a network for testing and validating network devices and configurations. |

# Other Sniffing and Spoofing Tools

| Tool Name | Interface | Description |
|------------|-----------|-------------|
| **Ettercap-plexec** | Command Line | A network security tool capable of performing Man-in-the-Middle (MITM) attacks, packet sniffing, protocol analysis, and remote command execution. |
| **Macchanger** | Command Line | A utility that changes the MAC address of a network interface to test security controls, improve privacy, or bypass MAC-based access restrictions. |
| **Minicom** | Text-Based UI | A serial communication program used for debugging, configuring, and communicating with devices connected through serial ports. |
| **mitmproxy** | Command Line / Text-Based UI | An interactive HTTP/HTTPS proxy that intercepts, inspects, modifies, and forwards web traffic during security testing. |
| **Responder** | Command Line | A penetration testing tool that responds to network authentication requests and captures credentials on local area networks (LANs). |
| **Scapy** | Command Line | A powerful packet manipulation tool used to create, send, capture, modify, and analyze custom network packets for penetration testing and network analysis. |
| **tcpdump** | Command Line | A command-line packet analyzer used to capture, monitor, and troubleshoot network traffic in real time. |
| **Wireshark** | GUI | A graphical network protocol analyzer used to capture, inspect, filter, and analyze network packets in detail. |
