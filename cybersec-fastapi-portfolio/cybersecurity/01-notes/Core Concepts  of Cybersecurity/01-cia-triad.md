# The CIA Triad

## Introduction

The **CIA Triad** is one of the most important concepts in cybersecurity. It is a security model used to protect information and ensure that systems remain secure.

The three core principles are:

* 🔒 **Confidentiality**
* ✔️ **Integrity**
* ⚡ **Availability**

These three principles work together to keep data secure, accurate, and accessible.

---

# CIA Triad Overview

| Principle           | Purpose                                              |
| ------------------- | ---------------------------------------------------- |
| **Confidentiality** | Prevent unauthorized access to information.          |
| **Integrity**       | Ensure data remains accurate and unaltered.          |
| **Availability**    | Ensure data and services are accessible when needed. |

---

---

# 1. Confidentiality

## What is Confidentiality?

**Confidentiality** means protecting information from unauthorized access. Only authorized users should be able to view sensitive data.

### Goal

Keep information **private and secure**.

### Real-Life Example

Think of a **diary with a lock**.

* Only the owner has the key.
* Other people cannot read its contents.

The same idea applies to digital information.

### Examples

* Password-protected accounts
* Bank account information
* Medical records
* Company confidential documents

### Common Security Methods

* Passwords
* Multi-Factor Authentication (MFA)
* Encryption
* Access Control
* User Permissions

---

# 2. Integrity

## What is Integrity?

**Integrity** ensures that data remains **accurate, complete, and unchanged** unless modified by an authorized person.

### Goal

Protect data from unauthorized modification or corruption.

### Real-Life Example

Imagine following a **recipe**.

Every time you cook, the recipe should remain the same unless the chef intentionally updates it.

If someone secretly changes the recipe, the final result may be incorrect.

### Examples

* Financial records
* Student grades
* Medical reports
* Software source code

### Common Security Methods

* Hashing
* Digital Signatures
* Checksums
* Version Control
* File Permissions

---

# 3. Availability

## What is Availability?

**Availability** means that information and systems are accessible whenever authorized users need them.

### Goal

Keep systems running and available.

### Real-Life Example

Imagine your favorite **book on a shelf**.

Whenever you want to read it, it should be available.

If the book is missing or locked away, it is unavailable.

### Examples

* Online banking
* Cloud storage
* Email services
* Company websites

### Common Security Methods

* Regular Backups
* Redundant Servers
* Load Balancing
* Disaster Recovery Plans
* UPS (Uninterruptible Power Supply)

---

# Treasure Chest Analogy

The CIA Triad can be understood using a simple treasure chest example.

```text
Treasure Chest

🔒 Confidentiality
Only trusted people have the key.

✔️ Integrity
The treasure inside has not been changed or stolen.

⚡ Availability
The chest is always available when you need it.
```

If any one of these protections fails, the treasure is at risk.

# Why the CIA Triad Is Important

The CIA Triad helps organizations:

* Protect sensitive information
* Prevent unauthorized access
* Maintain accurate data
* Keep services available
* Reduce cybersecurity risks
* Build secure systems

It serves as the foundation for many cybersecurity policies, standards, and best practices.

# What Happens If One Principle Fails?

| Principle Lost  | Possible Result                          |
| --------------- | ---------------------------------------- |
| Confidentiality | Sensitive information is leaked.         |
| Integrity       | Data becomes incorrect or tampered with. |
| Availability    | Users cannot access systems or data.     |

* **Availability** ensures systems and data are accessible when needed.
* All three principles must work together to provide effective cybersecurity.
