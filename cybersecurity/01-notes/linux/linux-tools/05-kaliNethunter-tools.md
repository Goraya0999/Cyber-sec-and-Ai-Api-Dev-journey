# Tools in Kali NetHunter

| Tool Name | Interface | Description |
|------------|-----------|-------------|
| **Metasploit** | Command Line / GUI | An exploitation framework optimized for NetHunter that allows ethical hackers to create, generate, and deploy payloads directly from Android devices. |
| **Wireshark** | GUI | A packet analysis tool adapted for NetHunter that captures, monitors, and analyzes network traffic in real time to identify vulnerabilities. |
| **Nmap** | Command Line | A powerful network scanner used to discover active hosts, scan open ports, identify running services, and map network structures. |
| **Hydra** | Command Line | A password-cracking tool that performs brute-force and dictionary attacks against various network protocols to test password strength. |
| **Crunch** | Command Line | A custom wordlist generator that creates password lists based on user-defined patterns for targeted penetration testing. |
| **Aircrack-ng** | Command Line | A wireless security suite used to test Wi-Fi security, capture wireless packets, crack Wi-Fi encryption, and assess wireless network defenses. |
| **Reaver** | Command Line | A Wi-Fi penetration testing tool that performs WPS (Wi-Fi Protected Setup) attacks to identify weaknesses in wireless networks. |
| **APKTool** | Command Line | A reverse engineering tool used to decompile, modify, and recompile Android APK files for vulnerability analysis and application testing. |
| **JADX** | GUI | A graphical reverse engineering tool that converts Android APK files into readable Java source code, making application analysis easier. |
| **Netcat (nc)** | Command Line | A versatile networking tool used for port scanning, banner grabbing, creating network connections, transferring data, and troubleshooting network services. |
| **BusyBox** | Command Line | A lightweight collection of Unix/Linux command-line utilities that provides essential system management, file handling, and networking commands on Android devices. |
